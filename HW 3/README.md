# HW 3 — useEffect, API, формы и useRef

Самостоятельный проект React + Vite по частям 5 и 6 материала:
https://github.com/yaroslavrychikin-crypto/log_test_safe/blob/main/fd.md

Выполнены обе основные практики и все 10 упражнений. Разделы переключаются в меню; при переключении компоненты размонтируются, запросы и таймеры очищаются. Данные форм не отправляются на сервер и не сохраняются после переключения раздела или перезагрузки.

## Запуск

Из общей папки `Angular and React`:

```bash
cd "Homework/HW 3"
npm ci
npm run dev -- --host 127.0.0.1
```

Нужен Node.js 20.19+ или 22.12+. Откройте адрес, который выведет Vite.

```bash
npm test
npm run build
npm run preview
```

## Основные практики

- **Каталог пользователей:** список и детали из JSONPlaceholder, отдельные состояния данных, загрузки и ошибки, пустой список и подсказка до выбора. API вынесен в `src/api.js`; `AbortController` отменяет запросы при смене пользователя и размонтировании. Результаты отменённых запросов не меняют состояние, даже если ответ успел прийти.
- **Регистрация:** управляемая форма, общий `handleChange`, имя, email, пароль, подтверждение, целый возраст 18–120 и согласие. Валидация вынесена в `src/utils/validation.js`, ошибки вычисляются при рендере, показ через `touched` после ухода из поля. Переключение видимости пароля, заблокированная невалидная отправка, сообщение об успехе, сброс и фокус через `useRef`. Пароль не сохраняется в сообщении об успехе.

## Упражнения

1. **Факты о кошках:** случайный факт при открытии, кнопка «Ещё факт», загрузка, ошибка и повторный запрос. API возвращает факты на английском.
2. **Погода:** город → геокодирование → текущая температура Open-Meteo. Обрабатывается отсутствие города. Отображается первый найденный город и его страна; можно уточнить название. Источник указан в интерфейсе.
3. **Пагинация:** посты JSONPlaceholder по 10 на страницу; страницы 1–10, кнопки «Назад/Вперёд», блокировка на границах.
4. **Поиск:** запрос пользователей по имени через 500 мс после последнего ввода; cleanup очищает таймер, предыдущий запрос отменяется. Пустая строка не вызывает запрос, есть состояние пустого результата.
5. **Отзыв:** имя, 1–5 звёзд, минимум 10 символов текста после удаления пробелов по краям, валидация, блокировка отправки, сброс.
6. **Страна/город:** город проверяется по учебному списку выбранной страны. Смена страны сразу меняет правило; доступные города указаны в поле.
7. **Фокус на ошибке:** самостоятельная форма контакта. При неудачной отправке первое невалидное поле получает фокус через refs. Кнопка остаётся доступной, чтобы можно было проверить этот сценарий.
8. **Файл:** неконтролируемый файловый input с ref, вывод имени и очистка выбора. Файл никуда не загружается.
9. **Бездействие:** через 30 секунд без действий в форме появляется «Всё ещё с нами?». Ввод, фокус, клавиатура и нажатие в форме перезапускают таймер. ID таймера хранится в ref, cleanup очищает его.
10. **Многошаговая форма:** личные данные → адрес → подтверждение, проверка каждого шага, фокус на ошибке, возврат с сохранением значений. Всё состояние формы находится в родительском компоненте; успешное подтверждение сбрасывает форму.

## Структура

- `src/api.js` — fetch, проверка HTTP-статуса, все адреса API.
- `src/hooks/useRequest.js` — эффект запроса и cleanup, защита от устаревших ответов.
- `src/components/ApiExercises.jsx` — каталог и упражнения 1–4.
- `src/components/RegistrationForm.jsx` — основная регистрация.
- `src/components/FormExercises.jsx` — упражнения 5–10.
- `src/components/Shared.jsx` — карточка, состояния запроса и поле с ошибкой.
- `src/utils/validation.js` — чистые правила валидации.
- `tests/validation.test.js` — проверки границ возраста, паролей, зависимых городов и отзыва.

API требуют подключения к интернету. Ошибки сети отображаются в интерфейсе. Документация погоды: https://open-meteo.com/en/docs и https://open-meteo.com/en/docs/geocoding-api.

## Самопроверка

- Быстро выбрать разных пользователей: показываются данные последнего выбора.
- Отключить сеть и открыть API-раздел: появляется сообщение об ошибке.
- В регистрации выйти из пустого поля; заполнить данные, переключить видимость пароля, отправить и проверить сброс.
- В поиске быстро ввести несколько букв: запрос отправляется после паузы 500 мс.
- В стране/городе ввести «Москва», выбрать Беларусь: появляется ошибка.
- В разделе фокуса отправить пустую форму, затем заполнить имя и повторить: фокус последовательно переходит на имя и email.
- В таймере не взаимодействовать с формой 30 секунд; после подсказки начать ввод.
- В многошаговой форме вернуться назад и проверить сохранность значений.
