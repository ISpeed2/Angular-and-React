# Soundspace

Каталог репетиционных студий на React и TypeScript. Выбор зала, времени и длительности репетиции.

## Возможности

- Главная, каталог, страница студии, избранное, бронирования, настройки и 404.
- Поиск по названию и оборудованию с debounce 300 мс.
- Фильтры по типу и району, сортировка по цене и вместимости; фильтры в URL.
- Форма бронирования: дата, время, длительность, состав, имя и телефон.
- Проверка вместимости, будущего времени, часов работы и пересечений с локальными активными бронями.
- Расчёт стоимости, отмена брони, история и фильтрация бронирований.
- Избранное, тёмная/светлая тема, сброс данных с подтверждением.
- Сохранение в localStorage, обработка ошибок чтения и записи.
- Контакты администратора через API: загрузка, ошибка, повторный запрос и кэш.
- Адаптивный интерфейс на CSS, иллюстрации залов на SVG.

## Стек

React 18, TypeScript, Vite, React Router 6, Context API, useReducer,
React Hook Form, Zod, TanStack Query 5.

## Источники данных

Каталог залов и оборудование описаны в `src/data/studios.ts`.
Контакты — тестовые профили готового публичного API JSONPlaceholder:
`GET https://jsonplaceholder.typicode.com/users`.
Запрос находится в `src/api/managers.ts`, хук TanStack Query — в `src/hooks/useManagers.ts`.
Для загрузки контактов нужен интернет. Имена и контакты из API не относятся к реальным студиям.

## Локальное хранение

Ключи: `soundspace:data:v1` (избранное и бронирования), `soundspace:theme` (тема).
Телефон и имя остаются в localStorage этого браузера и не отправляются в JSONPlaceholder.
Сброс в настройках очищает избранное и бронирования, сохраняя выбранную тему.

Собственного сервера и базы данных пока нет. Бронирования не отправляются в реальные студии.
Проверка пересечений работает только для записей в текущем браузере, без синхронизации вкладок
и устройств. Для общего расписания потребуется серверная проверка и база данных.

## Развёртывание

После `npm run build` статические файлы находятся в `dist`.
Хостинг должен перенаправлять неизвестные пути на `index.html` для работы BrowserRouter после F5.
