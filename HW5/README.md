# HW5 — Context API и продвинутые хуки

Выполнены две практики и все шесть упражнений из [частей 9–10 задания qwert.md](https://github.com/yaroslavrychikin-crypto/log_test_safe/blob/main/qwert.md). Самостоятельный React + Vite проект, организованный по образцу HW4.

## Запуск

```bash
cd Homework/HW5
npm ci
npm run dev -- --host 127.0.0.1
```

`npm run build` — production-сборка, `npm run preview` — её просмотр, `npm test` — тесты reducer’ов и структуры сохранённых задач. Для публикации BrowserRouter сервер должен отдавать index.html на маршрутах приложения.

## Пояснения для самопроверки

**Prop drilling** — передача данных через промежуточные компоненты, которым эти данные не нужны. Context позволяет потомкам получить значение непосредственно от ближайшего Provider. В этом проекте App и TodoPage не передают задачи в AddTask и TaskList через props.

**Два контекста.** TaskList подписан на задачи, AddTask — только на стабильный dispatch. Обновление списка не вызывает контекстного обновления формы. Это не блокирует её собственные рендеры при вводе текста или рендеры из-за других родителей.

**useReducer** собирает несколько переходов состояния в одной чистой функции. Он удобен для ADD/TOGGLE/DELETE/HYDRATE и действий корзины. Reducer не пишет в хранилище: сохранение выполняется в useEffect. Ленивая инициализация задач восстанавливает только массив с корректной структурой и уникальными ID; битый JSON восстанавливает пустой список.

**Мемоизация.** memo поверхностно сравнивает props. Reducer создаёт новый объект только для переключённой задачи, сохраняя остальные ссылки. TaskItem использует только контекст dispatch. useMemo сохраняет результат фильтрации до изменения списка или фильтра, useCallback сохраняет обработчики до изменения зависимостей. Мемоизация не нужна для каждого сложения или каждого обработчика: здесь она демонстрирует учебный паттерн. useCallback сам по себе не предотвращает рендер компонента.

**Границы Context.** Подходит для темы, пользователя и общего состояния небольшого приложения. Любое изменение значения Provider уведомляет всех его потребителей; memo не блокирует обновление контекста. Для высокочастотного и большого состояния нужны более узкие подписки, например селекторы внешнего хранилища.

**usePrevious** возвращает значение предыдущего рендера, а не предыдущего нажатия. Первый результат — undefined; обновление поиска на той же странице тоже вызывает рендер. **useDebounce** отменяет таймер при новом вводе и размонтировании.

## Проверка вручную

1. Добавьте две задачи, отметьте одну, переключите «Все / Активные / Готовые», удалите другую. Обновите страницу: список и отметка сохраняются.
2. В dev-консоли после добавления нескольких задач очистите лог и переключите одну. `render TaskItem` должен появляться только для изменённой строки. StrictMode может вызывать рендер дважды в разработке; это ожидаемо. Неизменённые строки сохраняют ссылки. Форма не рендерится из-за изменения списка, но рендерится из-за собственного ввода и очистки поля.
3. Переключите тему и обновите страницу: тема сохраняется на всех маршрутах.
4. Откройте `/profile` до входа: попадёте на `/login`. Введите имя, войдите и выйдите. После выхода доступ снова закрыт.
5. Добавьте книгу дважды и блокнот: 3 товара, итог 3450 ₽. Уменьшите количество книги: итог 1950 ₽. Проверьте удаление при уменьшении до нуля и очистку корзины.
6. В `/hooks` быстро введите «книга»: сначала «Печатает…», через 500 мс остаётся книга. Несуществующее название даёт пустой результат. Увеличьте и уменьшите счётчик, сравните предыдущее значение.
7. Замените `hw5:tasks` в localStorage на `{}` или битый JSON и обновите: приложение открывается с пустым списком.
8. Неизвестный маршрут показывает 404. На узком экране меню и карточки перестраиваются в одну колонку.

## Хранение и ограничения

В браузере сохраняются только `hw5:tasks` и `hw5:theme`. При недоступном localStorage выводится сообщение; работа продолжается в памяти. Вход и корзина хранятся в памяти Provider, переживают переходы по приложению, но сбрасываются после обновления. Авторизация учебная, без пароля, токена и сервера; серверные права доступа не имитируются. Поиск работает по локальным товарам без внешнего API.
