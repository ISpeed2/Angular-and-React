# Урок. React 19.2: компоненты, JSX, props и композиция.

## HW2 — упражнения по состоянию, событиям и спискам

Выполнены все 10 упражнений из конца файла «Часть 3, 4.html».
Основа — Todo List из `ANR 3`: сохранено разделение на `App`, `TodoForm`,
`Filters`, `TodoList` и `TodoItem`. Четыре упражнения части 3 доступны на той же странице.

Заголовок темы указан по заданию. Зависимости React и Vite перенесены из
`ANR 3` (React 19.3); сами упражнения посвящены частям 3 и 4 материала.

## Выполнено

1. Счётчик с кнопками `+1` / `-1` и управляемым полем шага. Обе кнопки
   используют указанный шаг; пустой, неположительный или некорректный шаг блокирует их.
2. Переключение `light` / `dark`: меняются фон, текст, поля и кнопки всей страницы.
3. Форма email + пароль: «Войти» доступна при заполнении обоих полей.
   При отправке показывается `alert` с email. Пароль в сообщение не выводится.
4. Список покупок: добавление и удаление товаров; пустые строки не добавляются.
5. Фильтрация Todo по приоритету, совместимая с фильтром по статусу.
6. Переключение сортировки по алфавиту (русская локаль) / дате добавления
   (от старых к новым). Дата показывается по московскому времени.
7. Поиск по подстроке без учёта регистра, совместимый с обоими фильтрами.
8. Прогресс-бар `done/total` и процент выполнения по всему списку.
   Для пустого списка отображается `0/0 (0%)`.
9. Редактирование по кнопке «Изменить» или двойному клику. Enter / «Сохранить»
   сохраняет, Escape / «Отмена» отменяет. Пустое название, включая пробелы,
   не сохраняется: поле остаётся открытым с сообщением об ошибке.
10. «Отметить все», «Удалить выполненные», «Очистить всё» работают со всем
    списком, включая задачи, скрытые поиском и фильтрами.

Состояние обновляется без мутаций через функциональные сеттеры, `map`, `filter`
и spread. Элементы получают стабильные ключи; счётчики и видимый список
вычисляются при рендере. Данные хранятся в памяти и сбрасываются при перезагрузке.

## Запуск

Из папки `Homework/HW2` (в корне ветки `Homework` — `HW2`):

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

Требуется Node.js 20.19+ или 22.12+. Адрес страницы выведет Vite.

```bash
npm run build
npm run preview
```

## Самопроверка

- Изменить шаг на 3: `+1` увеличивает счётчик на 3, `-1` возвращает назад.
- Переключить тему и проверить читаемость всех разделов.
- Заполнить email и пароль, отправить форму; проверить блокировку при пустом поле.
- Добавить два одинаковых товара и удалить один: второй остаётся.
- Совместить статус, приоритет и поиск; переключить сортировку.
- Попробовать сохранить название из пробелов, затем отменить редактирование.
- Отметить все задачи, проверить 100%, удалить выполненные — получится 0%.
- Добавить задачи и очистить весь список при включённом фильтре.
