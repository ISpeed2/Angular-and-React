# ANR 4 — Мои задачи

Развитие Todo List из ANR 3 с прежними стилями, приоритетами и редактированием.

## Запуск

```bash
npm install
npm run dev -- --host 127.0.0.1
```

## Проверка сборки

```bash
npm run build
```

Маршруты: `/` — приветствие и статистика, `/tasks` — список,
`/tasks/:taskId` — детали, остальные адреса — 404 без шапки.
Фильтры отражаются в URL: `?filter=active` и `?filter=done`.
Задачи сохраняются под ключом `tasks-app:v1` в localStorage;
три демо-задачи появляются только при отсутствии сохранённых данных.
Удаление требует подтверждения. Редактирование названия — кнопкой ✎,
Enter сохраняет, Escape отменяет изменения.

Для публикации сервер должен возвращать index.html для маршрутов приложения.
