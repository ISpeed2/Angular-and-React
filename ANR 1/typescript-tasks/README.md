# Задания по TypeScript

В `app.ts` выполнены все 24 задания. Необходимые демонстрации ошибок типов отмечены через `@ts-expect-error`, поэтому компиляция подтверждает ошибки и при этом завершается успешно.

## Компиляция и запуск всех заданий

```bash
tsc app.ts --ignoreconfig
node app.js
```

## Запуск части заданий

Для удобного просмотра и создания скриншотов можно передать диапазон:

```bash
node app.js 1-4
node app.js 5-8
node app.js 9-12
node app.js 13-16
node app.js 17-20
node app.js 21-24
```

Скриншоты выполнения находятся в папке `screenshots`.
