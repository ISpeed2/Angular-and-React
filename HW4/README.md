# HW4 — localStorage и React Router

Выполнены две основные практики и все восемь упражнений из частей 7–8 файла [аааа.md](https://github.com/yaroslavrychikin-crypto/log_test_safe/blob/main/%D0%B0%D0%B0%D0%B0%D0%B0.md).

## Запуск

```bash
cd Homework/HW4
npm install
npm run dev -- --host 127.0.0.1
```

Сборка: `npm run build`. Проверка собранного проекта: `npm run preview`.
При публикации сервер должен возвращать `index.html` для маршрутов приложения.

## Практика и упражнения

- `/todos` — Todo: добавление, отметка, удаление, фильтрация и очистка с подтверждением. Собственный хук `useLocalStorage`: ленивая инициализация, JSON, сохранение эффектом, проверка структуры, обработка ошибок чтения и записи.
- `/`, `/about`, `/users`, `/users/:userId`, `*` — практика роутинга: BrowserRouter в main.jsx, Routes/Route, Link/NavLink, useNavigate, useParams, общий Layout + Outlet и 404.
- **1. Счётчик** — `/storage`, состояние сохраняется после перезагрузки.
- **2. Тема** — кнопка в шапке; light/dark сохраняется и применяется скриптом в index.html до первого отображения.
- **3. Заметка** — `/storage`, debounce 500 мс через useEffect с очисткой таймера. Перед переходом дождитесь статуса «Сохранено»; переход до истечения задержки отменяет ожидающее сохранение.
- **4. Сброс** — `/storage`, подтверждение и очистка только четырёх ключей HW4. Сбрасывает и состояние, и ожидающий таймер заметки; чужие данные браузера сохраняются.
- **5. Блог** — `/posts`, `/posts/:id`, `/about`, главная `/`. Посты заданы массивом, неизвестный ID обрабатывается.
- **6. Хлебные крошки** — `/users/:userId`: Главная / Пользователи / Анна.
- **7. Защищённый маршрут** — `/admin`, константа `isAdmin = false` в src/App.jsx, Navigate на `/` с replace. Для проверки разрешённой ветки установите true. Это учебная клиентская проверка, не серверная авторизация.
- **8. Query-параметры** — `/users?city=Москва`, useSearchParams; фильтр восстанавливается по ссылке, история браузера работает.

## Структура

- `src/hooks/useLocalStorage.js` — чтение, проверка и сохранение.
- `src/components/Todo.jsx` — мини-проект Todo.
- `src/pages/Storage.jsx` — упражнения с хранилищем.
- `src/pages/RoutesPages.jsx` — страницы пользователей, блога, главная, о проекте и 404.
- `src/data.js` — учебные данные.
- `src/App.jsx` — маршруты, layout, тема и сброс.

## Самопроверка

1. Добавьте две задачи, отметьте одну, обновите страницу: текст и отметка остаются.
2. Увеличьте счётчик, включите тёмную тему, обновите: оба значения сохранены.
3. Введите заметку: до 500 мс виден статус ожидания, затем «Сохранено». Обновите страницу.
4. Нажмите «Сбросить всё», сначала отмените (данные остаются), затем подтвердите (счётчик 0, тема светлая, заметка и Todo пусты).
5. Откройте пользователей, выберите Москву: в URL `?city=Москва`, показаны Анна и Иван. Проверьте кнопки истории браузера.
6. Откройте профиль Анны: крошки, данные, кнопка «Назад». `/users/999` показывает отсутствие пользователя.
7. Откройте статьи, конкретную статью и `/posts/999`; проверьте навигацию без перезагрузки.
8. `/admin` перенаправляет на главную, неизвестный адрес показывает 404.
9. В DevTools замените `hw4:todos` на битый JSON или `{}` и обновите: приложение восстанавливает пустой список.

Ключи хранилища: `hw4:todos`, `hw4:count`, `hw4:theme`, `hw4:note`. Запись в недоступное хранилище показывает сообщение об ошибке. Внешние API не используются.
