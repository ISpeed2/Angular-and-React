# ANR 5 — React Hook Form, Zod и TanStack Query

Самостоятельная практика по частям 11–12 и комплексному заданию «Каталог постов». Основа и оформление Todo сохранены из ANR 4; сам ANR 4 не изменён.

## Запуск

```bash
cd "ANR 5"
npm install
npm run dev -- --host 127.0.0.1
```

Сборка: `npm run build`.

## Страницы

- `/` — главная и статистика задач.
- `/tasks`, `/tasks/:taskId` — Todo из ANR 4, фильтры в URL и сохранение в localStorage.
- `/forms` — создание пользователя (RHF + Zod), вход и заказ с динамическими товарами (`useFieldArray`). Адрес `taken@example.com` показывает пример серверной ошибки.
- `/posts` — список постов, поиск по заголовку, пагинация, оптимистичное удаление и ссылки на детали/редактирование.
- `/posts/new` — создание поста.
- `/posts/:id` — детали поста.
- `/posts/:id/edit` — редактирование тем же компонентом формы.

Форма поста проверяет заголовок, текст, автора, теги, статус и дату публикации. После отправки используются `mutateAsync`; ошибки с именем поля привязываются через `setError`. Query-хуки `usePosts()` и `usePost(id)` вынесены отдельно. Переход по ссылке из списка заранее кладёт пост в кэш деталей. Создание и удаление оптимистично меняют кэш; при ошибке удаление откатывает его.

Все запросы используют JSONPlaceholder. Он отвечает на POST, PUT и DELETE, но не сохраняет изменения; после синхронизации вернутся исходные данные. Удаление видно сразу благодаря оптимистичному обновлению. Форма умеет обрабатывать ответ сервера `{ field, message }`, хотя JSONPlaceholder такой ошибки не возвращает.

## Основные файлы

- `src/schemas/postSchema.js` — Zod-схема поста и значения формы.
- `src/components/PostForm.jsx` — общая форма создания и редактирования с динамическими тегами.
- `src/hooks/usePosts.js` — запросы, кэш и мутации TanStack Query.
- `src/api/posts.js` — GET, POST, PUT и DELETE запросы.
- `src/pages/PostsPage.jsx`, `NewPostPage.jsx`, `EditPostPage.jsx`, `PostDetailPage.jsx` — экраны каталога.
