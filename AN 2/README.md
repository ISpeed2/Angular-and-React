# AN 2 — взаимодействие, директивы, сервисы и DI

Выполнено [задание 3_4a.md](https://github.com/yaroslavrychikin-crypto/log_test_safe/blob/main/angular/3_4a.md): основной урок и задания 3.1–4.3.

## Запуск

```bash
cd "AN 2"
npm install
npm start -- --open
```

Адрес: http://localhost:4200/. Если AN 1 уже запущен на этом порту: `npm start -- --port 4201 --open`.

## Реализованные задания

| Задание | Реализация | Проверка вручную |
|---|---|---|
| 3.1 | `click-counter` | Нажмите +1 шесть раз, затем уменьшите ниже нуля: появятся подсказки |
| 3.2 | `shopping-list` | Добавление кнопкой и Enter, чекбоксы, зачёркивание, выполнено X из Y; удалите всё для проверки @empty |
| 3.3 | `todo-list` | Чекбоксы и три фильтра с подсветкой активного |
| 4.1 | `counter.service.ts`, `counter-a`, `counter-b` | Измените счётчик A: B обновится; доступен сброс |
| 4.2 | `cart.service.ts`, `add-to-cart`, `cart-view` | Добавьте один товар дважды: количество увеличится, сумма пересчитается; удаление и очистка |
| 4.3 | `favorites.service.ts`, `favorites-counter` | Переключите звезду: счётчик обновится; удаление задачи убирает её из избранного |

Все компоненты standalone. В шаблонах используются `@for`, `track`, `@empty`, `@if`, привязки событий, свойств и CSS-классов. Данные и операции вынесены в сервисы, сервисы внедряются через `inject()`.

Задачи и избранное хранятся в памяти и сбрасываются после перезагрузки страницы. Общий счётчик использует обычное числовое поле `count` в сервисе.

Корзина объединяет названия без учёта регистра, сохраняя исходную цену позиции. Отрицательная или некорректная цена и пустые названия не добавляются. Корзина, покупки и счётчики после перезагрузки сбрасываются.
