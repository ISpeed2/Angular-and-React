# ANR 3 — Todo List

Расширенный Todo List из практики части 4 файла «Часть 3, 4.html».
Компоненты и стили скопированы из учебного материала.

## Запуск

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Откройте адрес, который Vite выведет в терминале.

## Сборка

```bash
npm run build
```

В приложении работают добавление задач с приоритетом, отметка выполнения,
удаление, фильтры и счётчики. Для редактирования дважды нажмите на текст
задачи; Enter сохраняет, Escape отменяет изменения.
