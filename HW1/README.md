# Урок. Клиентский API layer: OpenAPI, ошибки, cancellation и session boundary

## HW1 — упражнения по React

Домашняя работа по разделу «Упражнения для закрепления» из `react1.md`.
Указанный выше заголовок сохранён по запросу; сам приложенный материал посвящён JSX, компонентам и пропсам, а не API layer.
По теме ему соответствует проект `ANR 2`, но каталога студентов из примера в существующих проектах нет. Здесь он реализован как самостоятельное приложение React + Vite.

## Выполнено

1. `Footer` с копирайтом подключён в `App`.
2. `Badge` принимает `text` и `color`; используется для курса и отметки отличника в `StudentCard`.
3. При `gpa >= 4.5` отображается «🏆 Отличник».
4. `StatCard` принимает `icon` и выводит его перед значением.
5. Аватары загружаются с `ui-avatars.com`; имя кодируется через `encodeURIComponent`. Для загрузки изображений нужен интернет.
6. Навыки вынесены в `SkillsList` с пропсом `skills`.
7. `StudentList` принимает `sortBy="name"` и сортирует по русскому алфавиту, не изменяя исходный массив.

**Ограничение исходника:** файл `react1.md` обрывается на строке задания №7: «принимай пропс `sortBy` (`'name'`». Реализована только видимая часть требования — сортировка по имени. Другие варианты сортировки и дальнейшие задания в файле отсутствуют.

## Запуск

Из папки `Homework/HW1`:

```bash
npm ci
npm run dev
```

Для Vite 8 нужен Node.js 20.19+ или 22.12+.

```bash
npm run build
npm run preview
```
